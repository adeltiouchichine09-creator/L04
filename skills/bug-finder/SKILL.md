# Bug Finder

Read the given Python exercise file with line numbers.

Compare each function with its docstring to understand what it should do.

Find all bugs in the file.

For each bug, write a report using exactly this format:

Line: <number>
Problem: <what is wrong and why>
Example: <input that shows the bug, actual result and expected result>
Fix: <the corrected line>

Write one block per bug.
Do not change the original code.
Do not write tests.
Do not add explanations outside the required format.

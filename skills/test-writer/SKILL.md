# Test Writer

Read the given bug report and the Python exercise file.

Use the Example from the bug report to create one test that proves the bug exists.

Return only valid Python code.

Write exactly one test function for the given bug report.

The function name must start with test_.

Use assert to compare the actual function result with the expected correct result.

The test must fail before the bug is fixed and pass after the bug is fixed.

The exercise functions are already imported in the test file.

Do not include imports, Markdown, explanations, or comments.
Do not fix the original exercise code.
